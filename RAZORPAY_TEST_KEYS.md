# How to Get Razorpay Test API Keys

This guide explains how to generate the Razorpay `KEY_ID` and `KEY_SECRET` required for the Razorpay FastAPI payment demo.

## 1. Create or Log In to Your Razorpay Account

Open the Razorpay Dashboard:

https://dashboard.razorpay.com/

Log in or create a Razorpay account.

## 2. Switch to Test Mode

After logging in, make sure the Dashboard is in **Test Mode**.

Test Mode is a sandbox environment. Payments are simulated, so no real money is charged.

## 3. Open API Keys

From the Razorpay Dashboard:

1. Go to **Account & Settings**.
2. Find **API Keys** under the website/app settings.
3. Click **Generate Key**.

Razorpay documentation:

https://razorpay.com/docs/payments/dashboard/account-settings/api-keys/
